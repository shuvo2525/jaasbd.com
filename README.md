# JAAS BD - Web Hosting & Domain Registration Bangladesh

A 1:1 complete, high-fidelity responsive clone of the DianaHost website customized with:
1. **Brand Name**: Replaced "DianaHost" with **JAAS BD** throughout the entire site.
2. **Official Logo**: Integrated the uploaded high-resolution bird/wing emblem logo.
3. **Harmonized Color Scheme**: Tailored the entire website design system to match the exact vibrant palette of the uploaded logo:
   - **Teal / Turquoise**: `#00D2B4` & `#06B6D4`
   - **Electric / Ocean Blue**: `#0284C7` & `#1E40AF`
   - **Royal Violet / Purple**: `#7C3AED` & `#9333EA`
   - **Solar Orange Accents**: `#FF6B00` & `#FFA000`
